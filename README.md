# Лабораторная работа № 1 по прикладной статистике

**Направление:** Инфохимия + Компьютерные Технологии в Дизайне

**Авторы:** Токарев М. - 502360, Зубенко Е. - 501468, Кузнецова А. - 505113, Сидорова А. - 504672, Короткова А. - 489551. Группа - 37.  

**Группа практики:** ПрикСтат Инф25 1.3, ПрикСтат КТвД25 1.1  

## Цель работы

Исследовать три случайные величины на химических данных:
изучить распределения и зависимости, проверить свойства оценок
и статистические гипотезы, затем реализовать генератор
на основе одной из исследованных величин.

## Данные

Используется авторская таблица экспериментальных оптических
свойств органических хромофоров.

Файл: `DB for chromophore_Sci_Data_rev03.csv`.

Источник данных:
https://doi.org/10.6084/m9.figshare.12045567

Статья с описанием:
https://doi.org/10.1038/s41597-020-00634-8

Выбранные величины:
- максимум поглощения, нм;
- максимум испускания, нм;
- квантовый выход флуоресценции, безразмерная величина;
- для анализа отобраны экспериментальные данные хромофоров в дихлорметане. Рабочая выборка после обработки исходных данных составила 1968 наблюдений.
