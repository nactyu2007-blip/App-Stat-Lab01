01 / Контекст

О чём это исследование

От экспериментальных данных — к статистическому описанию и вероятностной модели.

Исследовательская задача

Понять, как распределены оптические характеристики хромофоров, есть ли статистическая связь между ними и насколько выборочные оценки отражают характеристики исследуемого набора.

Отдельная задача второго спринта — построить генератор, моделирующий значения максимума поглощения.

Случайный эксперимент

Из рабочего набора равновероятно выбирается одна запись. Каждой из 1 968 записей соответствует вероятность выбора 1/1 968.

Случайность задаётся процедурой выбора записи из конечной совокупности. Значения характеристик конкретной записи при этом фиксированы.

05 / Выборки

Насколько выборка отражает совокупность?

В ноутбуке исследуется конечная совокупность из 1 968 записей и поведение оценок при изменении объёма выборки.

Два способа отбора

С возвращением. Каждая запись после выбора возвращается в набор и может быть выбрана повторно.

Без возвращения. Выбранная запись исключается из дальнейшего отбора.

Что сравнивали

Выборочные средние и дисперсии сопоставлялись с характеристиками всей конечной совокупности. Также оценивалась ошибка оценивания при увеличении размера выборки.

В эксперименте RMSE оценок среднего и дисперсии уменьшается при росте размера выборки — это эмпирически иллюстрирует повышение точности.

06 / Sprint 2

Генератор случайных величин

Метод Бокса — Мюллера: преобразование равномерных псевдослучайных чисел в стандартные нормальные, затем — в логнормальные.

Математическая идея

Для независимых U₁, U₂ ~ Uniform(0,1):

Z₁ = √(-2 ln U₁) · cos(2πU₂)

Z₂ = √(-2 ln U₁) · sin(2πU₂)

Полученные значения имеют стандартное нормальное распределение. Логнормальное значение получают преобразованием X = exp(μ + σZ).

07 / Итоги

К чему пришли

Результаты и ограничения исследования.

Основные выводы

  • Между максимумами поглощения и испускания обнаружена сильная положительная корреляция.
  • Для X и Y логнормальная модель предпочтительнее нормальной по критерию AIC.
  • Для квантового выхода требуется учитывать ограниченность диапазона и возможные значения на границах.
  • При увеличении размера выборки точность оценок в эксперименте повышается.
  • Метод Бокса — Мюллера позволяет получить нормальные значения, а экспоненциальное преобразование — логнормальные.

Ограничения

  • Рабочий набор трактуется как конечная совокупность; выводы относятся к нему и выбранной процедуре отбора.
  • Корреляция не доказывает причинность.
  • Предпочтение по AIC не означает абсолютного доказательства истинности распределения.
  • Синтетические данные воспроизводят выбранную статистическую модель, а не все физико-химические механизмы эксперимента.
